## 体验/复现路径

1. 在微信「设置」中查找「关怀模式」。
2. 开启关怀模式，观察字号、按钮和主要入口变化。
3. 打开聊天、通讯录、发现等主要页面，检查二级页面是否同样适配。
4. 尝试把一个复杂任务（例如添加提醒、查找服务）交给老人理解。
5. 检查系统提示词是否使用老人熟悉的表达，还是保留系统/产品术语。

## 观察结论

### 做得好的

- 官方明确说明关怀模式可以让文字与按钮更大、更清晰。
- 作为高频社交应用，老人可能已经具备基础使用习惯。

### 对老人使用的不足

- 关怀模式主要改变视觉尺寸，不等于任务结构被简化。
- 关怀模式本身不是事务管理工具，没有“提醒 → 完成 → 家属协作”的闭环。
- 页面中的“文字与按钮更大”主要解决“看得见”，没有解决“听得懂、点得动、有人接手”。

## 对本方案的影响

1. 适老化不能只做大字，必须同时减少步骤、明确反馈、提供语音和按钮替代路径。
2. 老人端文案使用“该吃药了”“不用她管了”等生活表达，而不是只保留系统术语。
3. 家属协作不能靠聊天工具里的手工转发，而应在原型中展示请求、回应、撤回和结果回执。
